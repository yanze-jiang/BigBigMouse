# 手动验收

以下项目需要实际用户设备。未勾选不代表通过；源码测试和构建不能验证物理设备输入。

## 安装

- [ ] 双击 DMG，能看到 BigBigMouse.app、Applications 快捷方式和安装说明。
- [ ] 将应用拖入 Applications，再从「应用程序」打开；推出 DMG 后仍可运行。
- [ ] 菜单栏显示应用图标，Dock 不显示常驻图标。
- [ ] 首次启动有中文授权引导；选择「稍后」不阻止正常使用电脑。
- [ ] 未授权时状态明确显示等待授权，不声称反转已经生效。
- [ ] 授予辅助功能权限后自动进入开启状态；若系统要求重开，重开后可用。
- [ ] 直接从 DMG、下载目录或构建目录打开，提示先安装，不出现系统授权提示或第二个滚动监听。
- [ ] 授权未生效时，「在 Finder 中显示当前应用」定位实际运行的副本。
- [ ] 「已授权但仍未生效…」→「重新打开应用」后，旧进程退出，新进程启动；菜单栏只保留一个图标。
- [ ] 已开启或主动关闭时，额外的授权恢复菜单隐藏。

## 蓝牙鼠标与触控板

前提：普通滚轮蓝牙鼠标已通过 macOS 配对，其他反转软件已退出；系统自然滚动保持用户原先的触控板习惯。

- [ ] 在 Safari 或其他长页面中，开启后向上和向下转鼠标滚轮，页面方向均相对关闭时反转。
- [ ] 慢速单格和快速多格滚动均正常，无卡顿、丢失或意外倍增。
- [ ] 紧接着用触控板双指滚动，方向与关闭本应用时一致。
- [ ] 触控板快速滑动松手后的惯性方向不变。
- [ ] 触控板横向滚动、缩放和系统多指手势不变。
- [ ] 在 Safari、Finder 长列表和文本编辑器中分别验证。
- [ ] 关闭开关后鼠标立即恢复原始方向；再次开启后重新反转。
- [ ] 关闭开关、退出并重开，仍然保持关闭。开启、退出并重开，保持开启。
- [ ] 退出应用后鼠标和触控板都恢复系统行为。

## 恢复与分发

- [ ] 蓝牙鼠标断开后重连，不需要重开应用。
- [ ] Mac 睡眠后唤醒、锁屏后解锁，反转仍正常。
- [ ] 撤销权限后打开菜单，状态变成等待授权；再次授权后能恢复。
- [ ] 多次打开同一个应用或另一份副本，不产生两个菜单栏图标或双重反转。
- [ ] 若另一位置的副本已在运行，新创建的进程显示双方位置；不静默继续监听。
- [ ] 系统将双击操作交给既有进程时，按更新说明退出旧版再打开新版，菜单栏显示 0.1.2。
- [ ] 退出并拖入新版替换，权限引导与状态仍清楚。
- [ ] 开机登录后应用不会自行启动。
- [ ] 正式签名公证后，从浏览器下载最终 DMG 到干净的 Mac，再完整验收安装和授权。
