# BigBigMouse 0.1.2

一个只反转普通鼠标上下滚轮、保留触控板方向的 macOS 菜单栏工具。

## 本版变化

- 增加安装位置提示，避免直接运行安装磁盘或下载目录里的副本。
- 新进程发现另一位置的副本已在运行时，明确显示位置，不再静默切回旧副本。
- 增加「已授权但仍未生效…」入口，可重新打开应用或前往系统设置；等待授权时也可在 Finder 定位当前应用。
- 菜单栏显示版本号，便于确认更新情况和反馈问题。
- 应用与 DMG 都包含 MIT 许可证；安装包附带中文授权排查说明。

普通使用仍然只有开关和退出，无开机自启、广告或联网功能。

## 下载与安装

Release 附件应包含：

- `BigBigMouse-0.1.2-universal.dmg`
- `BigBigMouse-0.1.2-universal.dmg.sha256`

双击 DMG，将应用拖入 Applications，再从「应用程序」打开并授予辅助功能权限。更新前请先从菜单栏退出旧版本。若权限仍对应旧版，按安装包中的授权排查说明操作。

兼容目标：macOS 13 或更新系统，原生支持 Apple M 系列芯片；通用安装包也包含 Intel 架构。部分高精度鼠标驱动和 Magic Mouse 不在兼容保证范围内。不同硬件和系统的实际测试范围见 [验证记录](VERIFICATION.md)。
